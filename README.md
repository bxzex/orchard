# Hollowmere

A website for a cider house that doesn't exist. The orchard, the seasons and the bottles are all drawn in code, so there are no images.

https://bxzex.github.io/orchard/

The hero is a canvas scene. Each tree grows from its own seed, so switching seasons redraws the same trees in blossom, fruit, autumn colour or snow. The branches sway more the further they are from the trunk.

The rest of it is a normal small-business site: four ciders, a year-at-the-orchard section and a booking form with real validation. The booking form is fake and doesn't send anything.
